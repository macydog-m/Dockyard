# 开源候选检查清单

本目录是从已整理源码导出的独立候选，版本为 `0.1.0-beta.3`。没有导入旧 Git 历史，
使用独立本地 Git 和全新的源码基线；远端准备阶段保持私有，不公开或发布。根包的 `private: true` 用于防止意外发布到 npm，
不影响未来在 GitHub 开源。

## 本地检查

- 核对导出清单，排除个人数据、凭据、旧安装包、缓存及内部规划。
- 使用锁文件重新安装依赖，运行自动化测试、桌面构建和记事本烟测。
- 核对 MIT、第三方许可、SVG 来源清单及构建输出。
- 扫描个人信息及秘密；不将扫描无命中视为绝对安全保证。

## 公开与发行前

- 审阅本地验收结果；复核 [依赖审计](dependency-audit.md) 中的剩余风险。
- 确定新仓库名称、简介、维护身份及安全报告渠道后，再创建私有远端。
- 核对本地初始提交及 noreply 身份，不导入或合并私有旧历史。
- 验证 GitHub CI 和安全设置，确认后才公开。CI 以 `main` 为默认分支。
- 从最终源码重新制作成品并验证干净 Windows 安装、升级、卸载和宿主连接。
- 公开源码与发布版本分别审阅，版本规则见 [版本与打包](releasing.md)。
